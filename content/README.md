# 内容源目录

此目录将逐步成为项目资料的人工维护来源。当前已有的 `开源项目资料/所有项目资料/` 保留为迁移依据，不删除、不覆盖。

后续每个项目使用 `content/projects/<project-id>/` 目录，建议包含：

- `project.yaml`：身份、卡片字段、分类关系与核验状态。
- `overview.md`：项目概览与适用范围。
- `theory.md`：理论架构与计算流程。
- `sources.yaml`：来源 URL、核验日期和备注。
- `references.yaml`：论文和引用资料。
- `media.yaml`：图片来源、版权和网页使用状态。

网页运行数据继续放在 `data/`。当内容迁移工具建立后，`data/` 应由本目录生成，不手工复制同一事实。
