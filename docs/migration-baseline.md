# 重构迁移基线

重构开始时，线上入口为根目录 `index.html`。以下数字用于每次发布前核对：

- 一级分类：9
- 二级分类：93

兼容性要求：

- 保留根目录 `index.html`。
- 保留现有自定义域名与 GitHub Pages 发布方式。
- 保留 `#category=<index>` 与 `#project=<slug>` 路由行为。
- 不在没有迁移映射的情况下改动项目 slug、源码链接或显示名称。

第一批重构已将 8 个内联样式块、内联应用脚本和嵌入式项目数据外置。页面视觉与交互不应因这一拆分发生变化。
