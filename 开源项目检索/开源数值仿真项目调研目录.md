# 数值仿真源码项目调研目录

> 核验日期：2026-07-24。本文在本轮检索中从零开始整理。
>
> 收录门槛：存在可下载、可克隆或可浏览的源码入口，并与当前分类直接相关。许可证、活跃度和项目规模**不作为筛除条件**；“待人工核验”表示源码仓库可访问，但本轮未逐项审读许可证文本。链接优先指向项目官网、官方代码托管组织或维护方明确给出的源码入口。

## 调研方法与使用说明

- 按现有全部二级标题分别检索中文/英文名、缩写、相邻技术词及 `source code`、`GitHub`、`GitLab` 等组合。
- 覆盖项目官网、GitHub、GitLab、研究机构与软件文档页；仅收录能落到源码入口的候选。
- 项目可跨分类。例如 MFEM 同时可服务 FEM、DG、IGA、高阶、AMR、MPI、GPU 与矩阵自由计算；这不是重复错误，而是该导航站需要表达的关系。
- `许可证状态`只表示本轮是否在项目主页/仓库页面看到明确许可证；后续可由人工逐条审核 SPDX、授权范围和第三方依赖。
- 空缺项不会以无关项目填充；后续若发现独立源码项目，可直接追加到对应表格行。
- 除非在项目总索引中另行标注，表内项目的许可证状态统一为“源码可得，许可证待人工核验”。

## 多维补漏调研记录（第二轮）

- 本轮不以既有二级标题作为唯一入口，而是交叉检索应用领域（结构/岩土、流体/航空、能源/核、材料、医学/生物力学、电磁/声学、地学、等离子体、分子/化学、海洋水利）与软件形态（完整求解器、开发库、领域框架、前后处理器、材料库、耦合器、教学/论文复现代码）。
- 同时用物理过程、空间尺度、离散对象、工作流位置、语言生态、计算平台、组织/实验室谱系、数据格式和同义词交叉发现候选；大型项目还追踪官方组织、下游求解器、适配器与模型库。
- 新发现项目优先落到现有二级标题；当前分类无法准确承接的项目保留在后文“其他（待分类）”，作为分类盲点的可见记录，而非排除或临时删除区。

## 分类修订建议（注释，不修改原分类）

1. `边界条件与初始条件构建`目前主要依附于 SALOME、PrePoMax、FreeCAD、Gmsh 等综合前处理器，尚未检索到数量足够的独立源码项目；建议保留标题，但页面展示为“前处理器能力集合”。
2. `前沿追踪与显式界面方法`可获取源码的独立通用项目较少，Basilisk/Gerris 是当前主要入口；建议保留以承接专题代码和未来论文复现仓库。
3. `近场—有限元耦合`及`非局部接触与界面模型`常作为近场或 FEM 框架的模块而非独立项目；建议保留，但后续以“项目 + 示例/模块”形式收录。
4. `结构化与块结构网格`与`六面体与高质量体网格`存在工具重叠，但用户检索意图不同，本轮不建议合并。
5. 建议新增为**标签**而非二级标题：`教学代码/论文复现`、`GPU 原生`、`工业验证案例`、`归档项目`。这些横向属性会跨越几乎所有分类。
6. “其他（待分类）”是兜底区，而不改动既有一级/二级标题。本轮整理后，OpenFAST、OpenModelica 与 Cantera 已补充到现有的 FSI、协同仿真或化学—热—力耦合条目；其核心系统级/基础库属性仍在“其他”保留。`多体动力学与系统仿真`、`蒙特卡洛粒子输运与辐射模拟`仍是没有准确二级标题的主要盲点；待同类项目积累后，再评估增设分类或横向标签。
