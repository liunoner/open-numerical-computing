# 开源数值仿真导航：项目规划与分类体系

## 1. 项目概述

### 1.1 项目名称

**开源数值仿真导航**（暂定）

### 1.2 项目定位

面向科研人员、工程师、学生和开源开发者的数值仿真工具导航网站。网站以数值方法和仿真工作流为主线，帮助用户从“要解决什么问题、采用什么计算路线”快速定位到合适的开源软件、计算库、网格工具、求解器和后处理工具。

网站不只是收集链接，而是建立“方法—工具—案例—工具链”的关系：用户既可以从有限元、有限体积、相场法等方法进入，也可以从网格、求解器、可视化等工作流环节进入。

### 1.3 服务对象

- 希望选择开源仿真软件的工程师与研究人员。
- 正在学习 FEM、FVM、SPH、相场法、近场动力学等方法的学生。
- 需要寻找数值计算框架、线性代数库、MPI/GPU 方案的开发者。
- 希望补齐“建模—网格—求解—后处理”开源工具链的团队。

### 1.4 核心价值

- **按技术路线发现工具**：从数值方法、建模框架和计算策略查找软件。
- **按仿真流程补齐工具链**：覆盖前处理、网格、求解、可视化与数据转换。
- **提供可比较的项目信息**：统一记录适用场景、语言、许可证、并行能力、文档和维护状态。
- **建立方法与软件的关联**：同一软件可被不同技术路线发现，避免单一目录造成的信息割裂。

### 1.5 分类与页面原则

- 左侧边栏固定展示九个一级标题，不展示嵌套菜单。
- 点击一级标题后，右侧完整展示该分类下的二级标题卡片。
- 点击二级标题后，直接进入方法/工具专题页或项目筛选结果；不再设置三级分类。
- 一个项目可对应多个二级标题。例如一个支持 FEM、相场、多物理场和 MPI 的框架应同时出现在相应结果中。
- 只有可稳定对应开源项目或开源工具生态的主题才作为二级标题；过细的知识点以标签、案例或文章形式呈现。

## 2. 一级分类总览

1. 建模与前处理
2. 网格生成与处理
3. 网格型离散
4. 无网格、粒子与格子
5. 相场、界面与断裂
6. 近场与非局部模型
7. 多尺度与多物理场
8. 求解器、高性能与计算策略
9. 后处理、可视化与数据转换

## 3. 一级分类与二级分类

## 3.1 建模与前处理

用于在求解之前创建、导入和配置仿真模型，包括几何、材料、边界条件和求解器输入准备。

| 二级分类 | 简介 |
| --- | --- |
| CAD 与实体几何建模 | 创建零件、装配体、实体与曲面几何。 |
| 参数化与脚本化几何建模 | 通过参数、脚本或 CSG 自动生成和修改几何。 |
| 几何内核与 CAD 二次开发 | 提供布尔运算、拓扑操作和 CAD 格式处理等底层几何能力。 |
| CAE 前处理与模型装配 | 将几何、材料、载荷、约束和分析步组织为可计算模型。 |
| 材料与本构模型开发 | 实现弹塑性、黏弹性、损伤、晶体塑性等材料行为。 |
| 边界条件与初始条件构建 | 创建边界分组、载荷、接触面、初始场及约束条件。 |
| 几何与模型格式互操作 | 在 CAD、网格和不同求解器输入格式之间导入、导出和转换。 |

## 3.2 网格生成与处理

用于将几何域离散为可供数值计算使用的网格，并完成质量控制、优化、适应和并行划分。

| 二级分类 | 简介 |
| --- | --- |
| 通用非结构网格生成 | 生成三角形、四面体和混合单元等通用非结构网格。 |
| 结构化与块结构网格 | 创建规则网格、多块网格和映射网格。 |
| 六面体与高质量体网格 | 面向六面体主导网格、棱柱层和高质量三维体网格。 |
| 曲面网格与几何离散化 | 对 CAD 曲面进行三角化、表面重建和离散化。 |
| 边界层与流体专用网格 | 创建近壁层、膨胀层和流动区域局部加密网格。 |
| 网格质量检测、修复与优化 | 检测畸变单元，并进行平滑、交换、修复和优化。 |
| 网格自适应与重网格 | 根据误差或物理场进行局部细化、粗化和重划分。 |
| 动网格与网格变形 | 服务于大变形、移动边界和流固耦合中的网格运动。 |
| 网格分区与负载划分 | 为 MPI 并行计算进行区域划分和负载平衡。 |
| 网格格式转换与数据读写 | 在 Gmsh、VTK、CGNS、Exodus、MED 等格式间转换。 |

## 3.3 网格型离散

以网格为基础，将连续方程离散为有限维代数系统的数值方法与框架。

| 二级分类 | 简介 |
| --- | --- |
| 连续 Galerkin 有限元法（FEM） | 使用连续有限元空间求解结构、传热、扩散和通用 PDE。 |
| 混合有限元与兼容离散 | 面向压力—速度、位移—压力及 H(div)、H(curl) 等混合问题。 |
| 高阶与 hp 有限元法 | 使用高阶形函数、p 加密和 hp 自适应提升计算精度。 |
| 有限体积法（FVM） | 基于控制体积守恒，常用于 CFD、传热和反应流问题。 |
| 有限差分法（FDM） | 在规则网格上通过差分格式求解扩散、波动和流动问题。 |
| 不连续 Galerkin 法（DG） | 适用于对流主导守恒律、高阶计算和复杂界面问题。 |
| 边界元法（BEM） | 通过边界积分求解无限域、声学、电磁和势流等问题。 |
| 谱方法与谱元法 | 面向平滑问题、湍流、波动和高精度高性能计算。 |
| 等几何分析（IGA） | 使用 NURBS 或样条函数统一几何表示与数值分析。 |
| 有限单元与嵌入式网格方法 | 在背景网格中处理复杂几何或嵌入式边界。 |

## 3.4 无网格、粒子与格子

以节点云、粒子、晶格或原子作为基本计算单元，适合大变形、颗粒、微观和介观问题。

| 二级分类 | 简介 |
| --- | --- |
| 无网格 Galerkin 方法 | 包括 EFG、MLS、RKPM 等基于节点云的连续体离散方法。 |
| 径向基函数方法（RBF） | 使用 RBF 插值或 RBF-FD 求解全局或局部无网格 PDE。 |
| 光滑粒子流体动力学（SPH） | 用于自由液面、大变形、流固耦合和流体颗粒模拟。 |
| 离散元法（DEM） | 模拟颗粒、岩土、粉体中的接触、碰撞和摩擦。 |
| 物质点法（MPM） | 使用粒子携带物质状态、背景网格计算，适合大变形和冲击。 |
| 粒子—网格法（PIC） | 用于等离子体、带电粒子和粒子—场耦合问题。 |
| 分子动力学（MD） | 在原子或分子尺度模拟材料与分子体系。 |
| 耗散粒子动力学与介观粒子法 | 面向复杂流体、软物质和介观尺度模拟。 |
| 格子 Boltzmann 法（LBM） | 用于流体、传热、多相流、多孔介质和介观流动。 |
| 元胞自动机与离散格子模型 | 用于凝固、生长、扩散、反应和规则驱动模拟。 |

## 3.5 相场、界面与断裂

用于描述相变、移动界面、裂纹、损伤、接触和不连续现象的建模与计算方法。

| 二级分类 | 简介 |
| --- | --- |
| 相场断裂 | 描述裂纹萌生、扩展、分叉及脆性或延性断裂。 |
| 相场微观组织演化 | 模拟凝固、相变、晶粒长大、析出和材料组织演化。 |
| 相场流体与两相流 | 使用 Cahn–Hilliard、Allen–Cahn 等模型处理相分离和界面流动。 |
| 水平集法（Level Set） | 用于移动界面、自由边界、形状演化和拓扑变化。 |
| 体积分数法（VOF） | 用于气液两相流、自由液面和界面捕捉。 |
| 前沿追踪与显式界面方法 | 显式表示和追踪界面，适合移动边界问题。 |
| 连续损伤力学 | 通过损伤变量描述材料退化和失效演化。 |
| 内聚区模型（CZM） | 用于界面脱粘、层合材料分层和裂纹扩展。 |
| 扩展有限元法（XFEM/GFEM） | 在不重新网格化的情况下处理裂纹、孔洞和不连续。 |
| CutFEM 与浸入式方法 | 在背景网格中处理复杂边界、流固界面和嵌入几何。 |
| 接触与摩擦计算 | 涵盖接触搜索、法向约束、摩擦滑移和多体接触。 |

## 3.6 近场与非局部模型

用于刻画材料或物理场在有限邻域内相互作用、具有尺度效应或长程作用的问题。

| 二级分类 | 简介 |
| --- | --- |
| 键基近场动力学 | 基于粒子键相互作用模拟近场断裂与损伤。 |
| 状态基近场动力学 | 支持更一般材料响应和泊松比的近场模型。 |
| 对应型近场动力学 | 将经典连续体本构关系嵌入近场框架。 |
| 近场断裂与损伤模型 | 用于裂纹萌生、断键、冲击和材料失效。 |
| 近场—有限元耦合 | 在局部使用近场模型、远场使用 FEM/FVM 的混合计算。 |
| 非局部积分型 PDE | 用于非局部扩散、非局部输运和积分微分方程。 |
| 分数阶 PDE 与分数阶本构 | 描述反常扩散、记忆效应和分数阶力学。 |
| 非局部本构与梯度增强模型 | 用于尺度效应、正则化损伤和应变梯度理论。 |
| 非局部接触与界面模型 | 描述非局部相互作用、黏附、断裂和界面行为。 |

## 3.7 多尺度与多物理场

用于连接不同空间尺度、时间尺度、物理过程或独立求解器的耦合计算。

| 二级分类 | 简介 |
| --- | --- |
| 均匀化与代表体元（RVE） | 从微观结构计算宏观等效材料性质。 |
| FE² 与计算均匀化 | 在宏观积分点嵌套微观有限元计算。 |
| 原子—连续体耦合 | 连接分子动力学、近场或颗粒模型与连续体模型。 |
| 微观结构—性能耦合 | 将晶粒、孔隙、相变等微观组织与宏观响应关联。 |
| 多尺度流动与传输 | 处理孔隙尺度、达西尺度、反应和传质的跨尺度问题。 |
| 流固耦合（FSI） | 联合求解流体载荷、结构变形和动网格。 |
| 热—结构耦合 | 同时计算温度场、热传导、热应力和热变形。 |
| 电磁—热—结构耦合 | 用于焦耳热、电磁力、感应加热等多场响应。 |
| 化学—热—力耦合 | 处理反应、扩散、相变、腐蚀和材料退化。 |
| 声学与振动耦合 | 面向声—结构耦合、波动传播和振动噪声。 |
| 协同仿真与求解器耦合 | 实现多软件数据交换、分区迭代和联合计算。 |

## 3.8 求解器、高性能与计算策略

用于将离散后的系统高效求解，并支持大规模并行、GPU 和高性能硬件。

| 二级分类 | 简介 |
| --- | --- |
| 稀疏直接求解器 | 使用 LU、Cholesky、LDLᵀ 等分解求解大型稀疏矩阵。 |
| Krylov 迭代求解器 | 包括 CG、GMRES、BiCGStab、MINRES 等迭代方法。 |
| 非线性求解器 | 包括 Newton、拟 Newton、Picard、线搜索和信赖域策略。 |
| 特征值与模态分析求解器 | 用于结构模态、稳定性、量子和波动问题。 |
| 常微分与偏微分时间积分 | 包括显式、隐式、半隐式、多步法和 Runge–Kutta 方法。 |
| 预条件技术 | 包括 ILU、AMG、块预条件、物理预条件和场分裂。 |
| 多重网格方法 | 包括几何多重网格、代数多重网格和 p 多重网格。 |
| 域分解方法 | 使用 Schwarz、FETI、BDD 等方法进行子域并行计算。 |
| 自适应网格与负载均衡 | 支持 AMR、动态重分区和并行自适应计算。 |
| MPI 与分布式内存并行 | 面向集群、多节点和并行稀疏线性代数。 |
| GPU 与异构加速 | 使用 CUDA、HIP、SYCL 等技术进行 GPU 加速计算。 |
| 矩阵自由与算子融合 | 避免显式组装矩阵，适合高阶 FEM 与 GPU 计算。 |
| 并行 I/O 与大规模数据处理 | 包括并行读写、检查点重启、压缩和存储。 |
| 性能可移植与硬件抽象 | 支持 CPU、GPU 与不同加速器之间的代码复用。 |

## 3.9 后处理、可视化与数据转换

用于读取、分析、比较和展示仿真结果，并实现科学数据格式的互操作。

| 二级分类 | 简介 |
| --- | --- |
| 通用科学可视化 | 查看网格、标量场、矢量场、张量场和时间序列结果。 |
| 有限元与结构结果后处理 | 分析位移、应力、应变、反力、模态和疲劳结果。 |
| 流场与传热结果后处理 | 分析流线、迹线、涡量、压力、温度、热流和边界层。 |
| 体渲染、切片与等值面 | 展示三维体数据、内部场、截面和等值面。 |
| 粒子与离散体系可视化 | 展示颗粒运动、接触网络、轨迹、原子和分子结构。 |
| 网格与几何查看 | 检查网格质量、单元属性、边界组和几何拓扑。 |
| 科学绘图与曲线分析 | 绘制收敛曲线、载荷—位移曲线、频谱、误差和统计图。 |
| 脚本化后处理与批量出图 | 使用脚本自动汇总参数扫描结果并批量生成图表。 |
| 科学数据格式读写与转换 | 支持 VTK、XDMF、CGNS、Exodus、HDF5、CSV 等数据格式。 |
| Web 与远程可视化 | 支持浏览器端三维查看、远程服务器和超算结果交互。 |
| 结果比较与数据分析 | 用于多算例比较、实验对照、误差场和结果回归分析。 |

## 4. 页面交互建议

左侧栏仅展示九个一级分类。用户点击一级分类后，右侧页面应包含：

1. 一级分类名称与一句话说明。
2. 全部二级分类卡片，每张卡片包含名称、简述和项目数量。
3. 常用筛选：应用领域、开发语言、许可证、操作系统、MPI/GPU、维护状态和学习难度。
4. 推荐项目与最近核验项目。

用户点击二级分类后，进入专题结果页，页面展示方法简介、相关开源项目、可运行案例、相关技术标签和替代方案。二级分类是网站的最细导航层级；更细的能力和应用方向应通过筛选标签表达。
