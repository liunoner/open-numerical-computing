## D. 源代码、生态与社区

- 官方源码入口：[h5py/h5py](https://github.com/h5py/h5py)，仓库 README 明确列为 h5py 源代码。
- 官网：项目以 [h5py 文档站](https://docs.h5py.org/en/stable/)和 GitHub 组织页作为主要官方入口，未见独立品牌官网。
- 官方文档：[h5py Documentation](https://docs.h5py.org/en/stable/)。
- 下载/发行页：[PyPI h5py](https://pypi.org/project/h5py/)；同时可从 [GitHub Releases](https://github.com/h5py/h5py/releases)获取源码发行信息。
- 许可证：BSD-3-Clause；以[仓库 LICENSE](https://github.com/h5py/h5py/blob/master/licenses/license.txt)和 PyPI 元数据为准。
- 安装与关键依赖：[安装/构建文档](https://docs.h5py.org/en/stable/build.html)说明 `pip install h5py` 的预构建 wheel 路径，源码构建依赖 Python、C 编译环境和 HDF5，MPI 支持另有说明。
- 社区入口（论坛/讨论/Issue/邮件列表）：[GitHub Issues](https://github.com/h5py/h5py/issues)为缺陷入口；文档还指向 h5py Google Groups 邮件列表。
- 插件、适配器与下游生态：h5py 是 Python 对 HDF5 的高/低层接口，与 HDF5 库、NumPy 及 Python 科学计算生态直接集成；MPI HDF5 构建受官方文档支持。
- 维护组织与主要开发者：由 GitHub `h5py` 组织和社区维护；具体核心维护者以[贡献者页](https://github.com/h5py/h5py/graphs/contributors)与项目元数据为准。
- 发展沿革：文档提供版本化页面，PyPI 与 GitHub Releases 保存发行历史；详细首发和治理演进待后续引用项目档案补充。
- 成熟度与维护状态（综合判断）：成熟、活跃维护。官方文档持续更新、PyPI 有当前发行；判断依据为官方文档、包发布与仓库，不以下载量推断。
