## D. 源代码、生态与社区

- 官方源码入口：[Geant4/geant4](https://github.com/Geant4/geant4)，并有 CERN GitLab 镜像/发行渠道。
- 官网：[Geant4](https://geant4.org/)
- 官方文档：[Geant4 Documentation](https://geant4.org/docs/)
- 下载/发行页：[Geant4 Download](https://geant4.org/download/) 与 [GitHub Releases](https://github.com/Geant4/geant4/releases)。
- 许可证：Geant4 Software License，见 [官方许可证页](https://www.geant4.org/download/license) 与仓库 LICENSE；不应误标为 GPL/MIT。
- 安装与关键依赖：CMake 构建，需 C++ 编译器及 Geant4 data datasets；GUI/可视化与 Python 等为可选，见 Installation Guide。
- 社区入口：[Geant4 Discourse](https://geant4-forum.web.cern.ch/)、[邮件列表](https://www.geant4.org/docs/mailing-list)、GitHub Issues 和用户/技术论坛。
- 插件、适配器与下游生态：官方 examples、physics lists、Geant4-DNA 等；GATE、TOPAS 等为建立在 Geant4 上的独立项目。
- 维护组织与主要开发者：Geant4 international collaboration，多机构共同维护；发布政策与工作组信息公开。
- 发展沿革：项目自 1990 年代末形成，发行/补丁政策、132+ GitHub releases 和文档保留演进。
- 成熟度与维护状态（综合判断）：成熟、活跃维护的大型国际物理输运工具包，近期官方发布和论坛机制持续运作。
