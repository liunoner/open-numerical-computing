## D. 源代码、生态与社区

- 官方源码入口：[clawpack/clawpack](https://github.com/clawpack/clawpack)
- 官网：[Clawpack](https://www.clawpack.org/)
- 官方文档：[Clawpack Documentation](https://www.clawpack.org/)
- 下载/发行页：[GitHub Releases](https://github.com/clawpack/clawpack/releases)；安装可通过 Conda/PyPI/源码等，见官方安装说明。
- 许可证：BSD-3-Clause，见 [LICENSE](https://github.com/clawpack/clawpack/blob/master/LICENSE)。各子包许可证以其仓库文件为准。
- 安装与关键依赖：推荐用 Conda 安装或从源码配置；Python/Fortran 编译环境和可选并行依赖按 [安装文档](https://www.clawpack.org/installing.html) 选择。
- 社区入口（论坛/讨论/Issue/邮件列表）：[Community](https://www.clawpack.org/community.html) 页面集中邮件列表、支持和 Issue 报告方式；各子库另有 Issues。
- 插件、适配器与下游生态：核心生态包括 Classic、AMRClaw、GeoClaw、PyClaw、VisClaw 和 Riemann solvers；详见 [求解器选择页](https://www.clawpack.org/whichclaw.html)。
- 维护组织与主要开发者：Clawpack 开发者社区与 GitHub 组织维护，是 [NumFOCUS affiliated project](https://numfocus.org/project/clawpack)。
- 发展沿革：项目的版本化文档、发行记录与开发者指南记录从早期 Fortran 到 Python/AMR 子项目的演进。
- 成熟度与维护状态（综合判断）：综合判断：成熟且活跃维护。官网持续发布版本化文档、维护社区入口和子项目生态；最近活动须以各仓库发行记录复核。
