## D. 源代码、生态与社区

- 官方源码入口：[HDFGroup/hdf5](https://github.com/HDFGroup/hdf5)，仓库明确标注为 Official HDF5 Library Repository。
- 官网：[The HDF Group — HDF5](https://www.hdfgroup.org/solutions/hdf5/)。
- 官方文档：[HDF5 最新文档](https://portal.hdfgroup.org/documentation/hdf5/latest/index.html)。
- 下载/发行页：[HDF5 Downloads](https://www.hdfgroup.org/downloads/hdf5/)与[GitHub Releases](https://github.com/HDFGroup/hdf5/releases)。
- 许可证：BSD-style HDF5 License；以[官方许可文本](https://support.hdfgroup.org/ftp/HDF5/releases/COPYING.html)和仓库 LICENSE 为准。
- 安装与关键依赖：仓库 [INSTALL.md](https://github.com/HDFGroup/hdf5/blob/develop/INSTALL.md)、[INSTALL_CMake.md](https://github.com/HDFGroup/hdf5/blob/develop/INSTALL_CMake.md)与 HPC README 说明 Autotools/CMake 构建；并行 HDF5 依赖合适的 MPI 配置。
- 社区入口（论坛/讨论/Issue/邮件列表）：[HDF Forum](https://forum.hdfgroup.org/)、[Help Desk](https://help.hdfgroup.org/)与[GitHub Issues](https://github.com/HDFGroup/hdf5/issues)均由官方仓库/官网明确指向。
- 插件、适配器与下游生态：官方说明 HDF5 有广泛生态；包括 C/C++/Fortran/Java 接口、VOL/VFD 插件机制及 HDFView 等工具，具体第三方项目需按项目单独核验。
- 维护组织与主要开发者：The HDF Group 是 HDF5 的开发者、维护者和 steward；完整开发人员名单以机构与仓库贡献者记录为准。
- 发展沿革：HDF5 起源于 NCSA，现由 The HDF Group 延续；官方仓库 releases 保存现代版本记录，细化年份后续以官方历史材料补充。
- 成熟度与维护状态（综合判断）：基础设施级、活跃维护。官方仓库和文档有近期正式发行，且机构提供论坛/支持；判断来自官方发布和维护入口。
