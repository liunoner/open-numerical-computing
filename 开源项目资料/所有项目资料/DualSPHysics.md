## D. 源代码、生态与社区

- 官方源码入口：[DualSPHysics/DualSPHysics](https://github.com/DualSPHysics/DualSPHysics)
- 官网：[DualSPHysics](https://dual.sphysics.org/)
- 官方文档：[GitHub Wiki](https://github.com/DualSPHysics/DualSPHysics/wiki) 与官网的用户指南/下载文档。

- 许可证：LGPL-2.1-or-later，见 [官方下载页](https://dual.sphysics.org/downloads/) 与仓库 [LICENSE](https://github.com/DualSPHysics/DualSPHysics/blob/master/LICENSE)。
- 安装与关键依赖：官网提供 Windows/Linux 包；源码/开发环境包含 C++、CUDA（GPU 版本）和 Visual Studio/Linux 编译路线，具体依赖随版本以官方指南为准。
- 社区入口（论坛/讨论/Issue/邮件列表）：[官方论坛](https://forums.dual.sphysics.org/)、[GitHub Issues](https://github.com/DualSPHysics/DualSPHysics/issues) 和用户研讨会。
- 插件、适配器与下游生态：官方包含 GenCase、DualSPHysics、PartVTK 等工具；VisualSPHysics 为独立 GPLv3 可视化项目，耦合扩展需按其源码单独核验。
- 维护组织与主要开发者：DualSPHysics 项目团队维护；官网版权页列出主要作者与协作研究机构。
- 发展沿革：官网说明 GitHub 承载 v5.4 源码及更频繁更新，下载页保留完整包与历史文档。
- 成熟度与维护状态（综合判断）：综合判断：成熟、具活跃用户社区。官方持续更新包、文档、论坛和研讨会；当前版本活跃度以发行页和仓库时间线复核。
