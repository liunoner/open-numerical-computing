## D. 源代码、生态与社区

- 官方源码入口：[FreeCAD/FreeCAD](https://github.com/FreeCAD/FreeCAD)
- 官网：[FreeCAD](https://www.freecad.org/)
- 官方文档：[FreeCAD Documentation Wiki](https://wiki.freecad.org/) 与 [Developers Handbook](https://freecad.github.io/DevelopersHandbook/)。
- 下载/发行页：[GitHub Releases](https://github.com/FreeCAD/FreeCAD/releases) 与 [官方下载页](https://www.freecad.org/downloads.php)。
- 许可证：LGPL-2.0-or-later，见 [LICENSE](https://github.com/FreeCAD/FreeCAD/blob/main/LICENSE) 与官方贡献政策。
- 安装与关键依赖：官方提供 Windows/macOS/Linux 预编译包；源码构建依赖 CMake、OpenCASCADE、Qt、Coin3D、Python 等，见开发者手册。
- 社区入口：[FreeCAD Forum](https://forum.freecad.org/)、[GitHub Issues](https://github.com/FreeCAD/FreeCAD/issues)、Discord、devtalk 和 Reddit。
- 插件、适配器与下游生态：Addon Manager、Workbench、FEM/BIM/CAM 等工作台及 FreeCAD Library；插件各自维护与授权需单独核验。
- 维护组织与主要开发者：FreeCAD Project Association（FPA）和全球贡献者社区；贡献者文件与官方治理页为依据。
- 发展沿革：GitHub releases、官方 blog、wiki 以及长期 Git 历史记录项目演进。
- 成熟度与维护状态（综合判断）：综合判断：成熟、活跃维护。多平台正式发行、文档、论坛和开发治理体系齐备。
