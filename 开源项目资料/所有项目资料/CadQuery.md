## D. 源代码、生态与社区

- 官方源码入口：[CadQuery/cadquery](https://github.com/CadQuery/cadquery)
- 官网：[CadQuery 项目主页](https://cadquery.github.io/)
- 官方文档：[CadQuery Documentation](https://cadquery.readthedocs.io/en/stable/)
- 下载/发行页：[GitHub Releases](https://github.com/CadQuery/cadquery/releases)；官方文档同时列出 CQ-editor 安装路径。
- 许可证：Apache-2.0，见 [LICENSE](https://github.com/CadQuery/cadquery/blob/master/LICENSE)
- 安装与关键依赖：官方推荐 Conda；亦可通过 pip 或源码安装。核心依赖 OCCT 的 Python 绑定等以 [安装文档](https://cadquery.readthedocs.io/en/stable/installation.html) 为准。
- 社区入口（论坛/讨论/Issue/邮件列表）：[GitHub Discussions](https://github.com/CadQuery/cadquery/discussions)、[Issues](https://github.com/CadQuery/cadquery/issues)；项目 README 还列出 Google Group 与 Discord。
- 插件、适配器与下游生态：CQ-editor 是其图形编辑器；官方 README 列出社区扩展 cq-kit 及项目案例，具体兼容版本须按发行说明核对。
- 维护组织与主要开发者：CadQuery GitHub 组织维护；公开贡献关系以仓库的贡献者与维护者列表为准。
- 发展沿革：项目从早期 CadQuery 演进为基于 OCCT 的 Python 参数化 CAD 框架；版本变更见 [发行记录](https://github.com/CadQuery/cadquery/releases)。
- 成熟度与维护状态（综合判断）：综合判断：活跃维护。官方站、文档和仓库均持续维护；具体最近发布及响应情况应以发行页和 Issue 时间线复核。
