## D. 源代码、生态与社区

- 官方源码入口：[BRL-CAD 官方 GitHub 仓库](https://github.com/BRL-CAD/brlcad)
- 官网：[BRL-CAD 官方主页](https://brlcad.org/)
- 官方文档：[官方编译文档](https://brlcad.org/wiki/Compiling) 与 [仓库 README](https://github.com/BRL-CAD/brlcad)
- 下载/发行页：[GitHub Releases](https://github.com/BRL-CAD/brlcad/releases)
- 许可证：以 [官方 COPYING](https://github.com/BRL-CAD/brlcad/blob/main/COPYING) 为准；项目 README 仅确认使用 OSI 批准的开源许可，精确 SPDX 待人工复核。
- 安装与关键依赖：CMake 源码构建；官方 README 提供 Windows、macOS、Linux 等平台文档，并说明发行资产含源码归档。
- 社区入口（论坛/讨论/Issue/邮件列表）：[GitHub Issues](https://github.com/BRL-CAD/brlcad/issues)、[BRL-CAD Zulip](https://brlcad.zulipchat.com/)；README 还列出邮件列表。
- 插件、适配器与下游生态：由 400+ 工具、几何脚本接口、光线追踪、几何分析与库组件构成；未发现独立官方插件市场。
- 维护组织与主要开发者：BRL-CAD Development Team；官方仓库与 brlcad.org 是公开维护入口。
- 发展沿革：官方 README 记载项目自 1979 年持续开发，2004 年以开源软件发布。
- 成熟度与维护状态（综合判断）：综合判断：长期活跃成熟项目。官方发行、源码、跨平台构建文档和社区入口均持续可访问。
