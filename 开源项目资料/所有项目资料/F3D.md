## D. 源代码、生态与社区

- 官方源码入口：[f3d-app/f3d](https://github.com/f3d-app/f3d)
- 官网：[F3D](https://f3d.app/)
- 官方文档：[F3D Documentation](https://f3d.app/documentation/)
- 下载/发行页：[Download](https://f3d.app/download/) 与 [GitHub Releases](https://github.com/f3d-app/f3d/releases)。
- 许可证：BSD-3-Clause，见 [官方许可页](https://f3d.app/LICENSE/)。
- 安装与关键依赖：官方提供 Windows/macOS/Linux/Android 包，支持 pip、npm 和多种系统包管理器；源码构建使用 CMake/vcpkg，详见 [构建文档](https://f3d.app/dev/BUILD/)。
- 社区入口（论坛/讨论/Issue/邮件列表）：[GitHub Issues](https://github.com/f3d-app/f3d/issues)、[Discussions](https://github.com/f3d-app/f3d/discussions) 和官方 Discord。
- 插件、适配器与下游生态：提供 Python library、Web/WASM package；基于 VTK、OCCT、Assimp 等依赖，扩展包需与核心区分。
- 维护组织与主要开发者：F3D-APP Foundation 与 f3d-app GitHub 组织维护；项目源自 Kitware SAS。
- 发展沿革：官网 changelog 和 GitHub releases 记录从 Kitware 发起到 Foundation 维护及多平台扩展。
- 成熟度与维护状态（综合判断）：综合判断：活跃维护。当前有稳定版、nightly、连续文档与社区入口。
